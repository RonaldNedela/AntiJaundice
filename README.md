# AntiJaundice

Hey everyone!

Many iPad Pro 10.5” (2017) owners—and users of several other older iPads—are familiar with the notorious display aging issue where a distinct yellow border creeps in around the edges of the screen.

To combat this hardware defect, I developed AntiJaundice a lightweight tweak that injects a subtle, customizable blueish tint along the display perimeter to visually neutralize the yellowing.

Key Features
* **Color Neutralization:**Blends a cool overlay specifically over the affected borders.
* Smart Screenshot Hook: Automatically hides the overlay during screen captures, so your screenshots remain clean and color-accurate without any blue borders.
Full Fine-Tuning (via Settings):
**Enabled:**Master toggle on/off.
**Edge Offset (0 – 40 px)**Adjust where the effect begins relative to the bezel.
**Band Width (50 – 250 px):**Set how deep into the screen the gradient extends.
**Intensity (0.1% – 20%):**Fine-tune the opacity to match the severity of the yellowing.
**Color Hue (0 – 100):**Tweak the tint tone to perfectly counter your display’s specific discoloration.

Compatibility & Details
**Tested on:**iPad Pro 10.5” (2017), iOS 17.7.11.
Architecture: Rootless
Price: Free
